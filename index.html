Build a Pro-Level AI Meeting Assistant

Learn how to build a fully-featured, serverless web application complete with Dark Mode, Markdown exports, and intelligent data extraction using the cutting-edge Gemini 3.8 Flash API.

Welcome! In this workshop, you will build an app that takes messy meeting transcripts and instantly extracts clean summaries, key discussion points, and structured action items in a beautiful UI.

Step 1: Get Your Free Gemini API Key

To let your browser talk to Google's AI models, you'll need an API key. This is a secure string of text that tells Google you are authorized to use their services.

Do I have to pay for this?

Absolutely not! Google offers a generous Free Tier which is perfect for this workshop. It gives you access to their flagship models (like gemini-3.8-flash) with the only limitation being a slightly lower rate limit (fewer requests per minute). No credit card is required!

  1. Go to Google AI Studio and sign in.
  2. Click Get API key in the left-hand dashboard.
  3. Click Create API key, copy it, and keep it somewhere handy.

Step 2: Set Up Your Workspace

Web browsers are incredibly powerful. This entire application will run locally on your machine without a database or server!

  1. Create a folder on your computer named meeting-assistant.
  2. Inside it, create a single new file named index.html.
  3. Open index.html in your favorite code editor (like VS Code, Notepad++, or Cursor).

Step 3: Building the Code (Copy & Paste)

3.2 Application Logic & Settings (JavaScript Part 1)

Now we open a <script> tag where our JavaScript will live. This chunk handles the Dark Mode toggle, our Tabs, and safely saves the user's API Key using the browser's local storage (meaning it never touches a database!).

Paste this immediately below the HTML chunk you just pasted:

index.html (Part 2: UI & Settings JS)
    <script>
        // 1. Theme Management (Dark/Light Mode)
        const themeToggleBtn = document.getElementById('theme-toggle');
        const htmlElement = document.documentElement;
        if (localStorage.theme === 'dark' || (!('theme' in localStorage) && window.matchMedia('(prefers-color-scheme: dark)').matches)) {
            htmlElement.classList.add('dark');
        }
        themeToggleBtn.addEventListener('click', () => {
            htmlElement.classList.toggle('dark');
            localStorage.theme = htmlElement.classList.contains('dark') ? 'dark' : 'light';
        });

        // 2. API Key Modal & LocalStorage
        const settingsModal = document.getElementById('settings-modal');
        const apiKeyInput = document.getElementById('api-key-input');
        let userApiKey = localStorage.getItem('gemini_api_key') || '';
        if (userApiKey) document.getElementById('api-key-status-text').textContent = 'Key Saved';

        document.getElementById('open-settings').addEventListener('click', () => {
            apiKeyInput.value = userApiKey;
            settingsModal.classList.remove('hidden');
        });
        document.getElementById('close-settings').addEventListener('click', () => settingsModal.classList.add('hidden'));
        document.getElementById('save-api-key').addEventListener('click', () => {
            userApiKey = apiKeyInput.value.trim();
            localStorage.setItem('gemini_api_key', userApiKey);
            document.getElementById('api-key-status-text').textContent = 'Key Saved';
            settingsModal.classList.add('hidden');
            showToast('API key saved locally!');
        });

        function showToast(msg) {
            const toast = document.getElementById('toast');
            document.getElementById('toast-msg').textContent = msg;
            toast.classList.remove('translate-y-16', 'opacity-0');
            setTimeout(() => toast.classList.add('translate-y-16', 'opacity-0'), 4000);
        }

        // 3. File Upload Handler
        document.getElementById('file-upload').addEventListener('change', (e) => {
            const file = e.target.files[0];
            if (!file) return;
            const reader = new FileReader();
            reader.onload = (event) => document.getElementById('notes-input').value = event.target.result;
            reader.readAsText(file);
        });

        // 4. Tab Switching Logic
        const tabBtns = document.querySelectorAll('.tab-btn');
        tabBtns.forEach(btn => {
            btn.addEventListener('click', (e) => {
                tabBtns.forEach(b => b.className = "tab-btn px-3 py-1.5 rounded-md text-slate-600 dark:text-slate-400");
                e.target.className = "tab-btn px-3 py-1.5 rounded-md bg-white dark:bg-slate-700 text-slate-800 dark:text-white shadow-sm";
                
                if (e.target.getAttribute('data-tab') === 'structured') {
                    document.getElementById('structured-output').classList.remove('hidden');
                    document.getElementById('markdown-output').classList.add('hidden');
                } else {
                    document.getElementById('structured-output').classList.add('hidden');
                    document.getElementById('markdown-output').classList.remove('hidden');
                }
            });
        });

3.3 The AI Brain (JavaScript Part 2)

This final piece is the true magic. We use the Gemini 3.8 Flash model along with a strict JSON schema to force the AI to return data as predictable code.

The Smart Extractor & Timeout: Because parsing heavy files can take 15-25 seconds, we added an AbortController to prevent the app from hanging infinitely. We also include a Regex Extractor to strip out any extra conversational words (like "Here is your data!") that the AI might accidentally output.

Paste this final chunk immediately below the last one to complete your app!

index.html (Part 3: Gemini API Logic)
        // 5. Processing & Gemini API Call
        let lastParsedData = null;

        document.getElementById('process-btn').addEventListener('click', async () => {
            const rawNotes = document.getElementById('notes-input').value.trim();
            if (!rawNotes || !userApiKey) return showToast('Check Notes & API Key!');

            // Set Loading State
            document.getElementById('empty-state').classList.add('hidden');
            document.getElementById('structured-output').classList.add('hidden');
            document.getElementById('markdown-output').classList.add('hidden');
            document.getElementById('loading-state').classList.remove('hidden');
            
            // Dynamic UI Updates while waiting
            const loadingText = document.getElementById('loading-text');
            loadingText.textContent = 'Synthesizing Meeting Intelligence...';
            const slowLoadTimer = setTimeout(() => loadingText.textContent = 'Still thinking... Organizing complex data...', 6000);
            
            // 35 Second Timeout to prevent infinite hanging
            const controller = new AbortController();
            const timeoutId = setTimeout(() => controller.abort(), 35000);

            const apiUrl = `https://generativelanguage.googleapis.com/v1beta/models/gemini-3.8-flash:generateContent?key=${userApiKey}`;
            
            const payload = {
                contents: [{ parts: [{ text: `Organize these notes into JSON:\n\n${rawNotes}` }] }],
                systemInstruction: { parts: [{ text: "You are an executive assistant. Output ONLY valid JSON containing summary, keyDiscussions, actionItems (task, assignee, deadline), and followUps." }] },
                generationConfig: {
                    responseMimeType: "application/json",
                    responseSchema: {
                        type: "OBJECT",
                        properties: {
                            summary: { type: "STRING" },
                            keyDiscussions: { type: "ARRAY", items: { type: "STRING" } },
                            actionItems: { type: "ARRAY", items: { type: "OBJECT", properties: { task: { type: "STRING" }, assignee: { type: "STRING" }, deadline: { type: "STRING" } } } },
                            followUps: { type: "STRING" }
                        }
                    }
                }
            };

            try {
                let response = await fetch(apiUrl, {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify(payload),
                    signal: controller.signal
                });

                clearTimeout(timeoutId);
                clearTimeout(slowLoadTimer);

                if (!response.ok) throw new Error(`API Error: ${response.status}`);
                let result = await response.json();
                
                let jsonText = result.candidates[0].content.parts[0].text;
                // SMART EXTRACTOR: Isolate JSON to prevent hallucination crashes
                let jsonMatch = jsonText.match(/\{[\s\S]*\}/);
                jsonText = jsonMatch ? jsonMatch[0] : jsonText.replace(/```json/gi, '').replace(/```/gi, '').trim();
                
                lastParsedData = JSON.parse(jsonText);
                renderResults(lastParsedData);
                
            } catch (err) {
                clearTimeout(timeoutId);
                clearTimeout(slowLoadTimer);
                if (err.name === 'AbortError') {
                    showToast('Request timed out. Google API is busy. Try again.');
                } else {
                    showToast(err.message || 'Error processing notes. Check API Key.');
                }
                document.getElementById('loading-state').classList.add('hidden');
                document.getElementById('empty-state').classList.remove('hidden');
            }
        });

        // 6. Display the Results
        function renderResults(data) {
            document.getElementById('loading-state').classList.add('hidden');
            document.getElementById('structured-output').classList.remove('hidden');
            document.getElementById('action-buttons').classList.remove('hidden');

            document.getElementById('out-summary').textContent = data.summary || "No summary provided.";
            
            const discussionsList = document.getElementById('out-discussions');
            discussionsList.innerHTML = '';
            (data.keyDiscussions || []).forEach(point => discussionsList.innerHTML += `<li class="flex"><i class="fa-solid fa-check text-emerald-500 mr-2 mt-1"></i>${point}</li>`);

            const tbody = document.getElementById('out-actions-tbody');
            tbody.innerHTML = '';
            (data.actionItems || []).forEach(item => {
                tbody.innerHTML += `
                    <tr><td class="p-3 border-b border-slate-100 dark:border-slate-800">${item.task}</td>
                    <td class="p-3 border-b"><span class="px-2 py-1 bg-emerald-100 text-emerald-700 rounded-full text-xs">${item.assignee}</span></td>
                    <td class="p-3 border-b text-xs text-slate-500">${item.deadline}</td></tr>`;
            });
            
            document.getElementById('out-followups').textContent = data.followUps || "None";

            // Setup Markdown string for export
            let mdContent = `# Meeting Summary\n\n${data.summary}\n\n## Action Items\n` +
                data.actionItems.map(a => `- [ ] ${a.task} (@${a.assignee} by ${a.deadline})`).join('\n');
            document.getElementById('markdown-output').innerHTML = marked.parse(mdContent);
            
            // Export Button Logic
            document.getElementById('export-md-btn').onclick = () => {
                const a = document.createElement('a');
                a.href = URL.createObjectURL(new Blob([mdContent], { type: 'text/markdown' }));
                a.download = 'meeting-notes.md';
                a.click();
            };
        }
    </script>
