Build Your Own AI Meeting Assistant

Learn how to build a lightweight, serverless web application that runs entirely in your web browser. Turn messy notes into structured action items instantly using the Gemini API.

Welcome! In this workshop, you will build an app that takes messy meeting notes and uses the Gemini API to instantly extract clean summaries, key discussion points, and structured action items with assignees and deadlines.

What You Will Learn

  1. How to Get a Gemini API Key: Generating your free developer key using Google AI Studio.
  2. The Power of Client-Side Apps: How to build a fully functional web app using a single HTML file—no backend server, databases, or complex hosting required.
  3. Modern Frontend Styling: Using Tailwind CSS via CDN to instantly style your app with professional design.
  4. Gemini API Integration: Connecting directly from the browser to Google's Gemini AI model (gemini-3.8-flash) using Structured Outputs to get reliable data every time.

Step 1: Get Your Free Gemini API Key

To let your browser talk to Google's AI models, you'll need a free API key from Google AI Studio.

Why do you need an API key?
AI models like Gemini run on powerful servers at Google. To use them, your web app needs to send a request over the internet. The API key acts like a secure, digital ID badge. It tells Google that you have permission to use the service and connects your web app's requests to your developer account.

  1. Open your web browser and go to Google AI Studio.
  2. Sign in with your Google account.
  3. In the top left or center of the dashboard, click on Get API key.
  4. Click Create API key in new project (or select an existing Google Cloud project if prompted).
  5. Copy your newly generated API key and save it somewhere safe. You will paste this into your web app when you test it!

Step 2: Set Up Your Workspace

You don’t need any heavy software development environments or complex installations to get started.

  1. Create a new folder on your computer named meeting-assistant.
  2. Inside that folder, create a single file named index.html.
  3. Open index.html in your favorite code editor (like VS Code, Notepad++, or TextEdit).

Step 3: Building the Application Code

We are going to build this entire application inside your index.html file by copying and pasting three specific chunks of code. Before we build, let's understand how the AI's brain will work.

3.1 What Output Should You Expect?

When you paste messy notes like "John said he will email the client by Tuesday", we don't just want the AI to write a generic paragraph back. We want to build a real tool.

To do this, we use a feature called Structured Outputs. We write instructions in our code that force the Gemini AI to reply in a strict, predictable data format called JSON. The AI's hidden output will look like this:

JSON Output Example
{
  "summary": "Quick touch-base on client outreach.",
  "actionItems": [
    { 
      "task": "Email the client", 
      "assignee": "John", 
      "deadline": "Tuesday" 
    }
  ]
}

Because the data is perfectly structured, our JavaScript code can easily read it and instantly draw a beautiful, organized table on the screen!

3.3 API Key Management (JavaScript Part 1)

Now we need to add the logic to make the app interactive. We open a <script> tag at the bottom of our HTML.

This first JavaScript section handles the API Key. We don't want users to type their key every time they refresh the page. So, we use a feature called localStorage to save the key securely in the user's browser. It also controls opening and closing the pop-up modal.

Paste this code immediately below the HTML you just pasted in index.html:

index.html (Part 2: API Key JS)
    <script>
        // --- SECTION 1: API Key Management ---
        // Check if the user already saved a key in their browser
        let userApiKey = localStorage.getItem('gemini_api_key') || '';
        
        // Open the settings modal when the button is clicked
        document.getElementById('open-settings').onclick = () => {
            document.getElementById('api-key-input').value = userApiKey; // Show current key
            document.getElementById('settings-modal').classList.remove('hidden');
        };

        // Save the key when the save button is clicked
        document.getElementById('save-api-key').onclick = () => {
            userApiKey = document.getElementById('api-key-input').value.trim();
            localStorage.setItem('gemini_api_key', userApiKey); // Save to browser storage
            document.getElementById('settings-modal').classList.add('hidden'); // Hide modal
            alert("API Key Saved!");
        };

3.4 The AI Logic (JavaScript Part 2)

This final piece of code is the true "brain" of our application. Here is exactly what it does when you click the "Transform Notes" button:

  1. Grabs your text: It reads what you pasted using document.getElementById().
  2. Builds the Prompt: It creates a configuration object. Notice the responseSchema section—this is where we strictly enforce that Gemini must reply in JSON format with an array of action items.
  3. Calls the API: It securely sends your notes and your secret API key to Google's servers using fetch().
  4. Updates the Screen: When Google replies, the code loops through the actionItems list and draws a new table row (<tr>) for every task!

Paste this final chunk immediately below the last one to finish your app:

index.html (Part 3: Gemini API Logic)
        // --- SECTION 2: AI Processing Logic ---
        document.getElementById('process-btn').addEventListener('click', async () => {
            const rawNotes = document.getElementById('notes-input').value.trim();
            
            // Check if user is ready
            if (!userApiKey) { alert("Please click the 'API Key' button at the top to add your key first!"); return; }
            if (!rawNotes) { alert("Please paste some notes first!"); return; }

            // Show loading spinner, hide old results
            document.getElementById('structured-output').classList.add('hidden');
            document.getElementById('loading-state').classList.remove('hidden');

            // Set up the API URL with your key (Updated to gemini-3.8-flash for stability)
            const apiUrl = `https://generativelanguage.googleapis.com/v1beta/models/gemini-3.8-flash:generateContent?key=${userApiKey}`;
            
            // Build the specific instructions for Gemini
            const payload = {
                contents: [{ parts: [{ text: `Organize these meeting notes:\n\n${rawNotes}` }] }],
                systemInstruction: { parts: [{ text: "Extract summary and actionItems (task, assignee, deadline)." }] },
                generationConfig: {
                    responseMimeType: "application/json", // Force JSON output!
                    responseSchema: {
                        type: "OBJECT",
                        properties: {
                            summary: { type: "STRING" },
                            actionItems: {
                                type: "ARRAY",
                                items: {
                                    type: "OBJECT",
                                    properties: { task: { type: "STRING" }, assignee: { type: "STRING" }, deadline: { type: "STRING" } }
                                }
                            }
                        }
                    }
                }
            };

            // Send the request to Google
            try {
                let res = await fetch(apiUrl, { 
                    method: 'POST', 
                    headers: { 'Content-Type': 'application/json' }, 
                    body: JSON.stringify(payload) 
                });
                
                let json = await res.json();

                // Smart extraction to prevent markdown crashes
                let rawText = json.candidates[0].content.parts[0].text;
                const jsonMatch = rawText.match(/\{[\s\S]*\}/);
                if (!jsonMatch) throw new Error("Could not extract JSON from AI response.");
                let data = JSON.parse(jsonMatch[0]);
                
                // Update the HTML interface with the new data
                document.getElementById('loading-state').classList.add('hidden');
                document.getElementById('structured-output').classList.remove('hidden');

                document.getElementById('out-summary').textContent = data.summary;
                document.getElementById('out-actions-tbody').innerHTML = data.actionItems.map(item => 
                    `<tr>
                        <td class="p-2 border-b">${item.task}</td>
                        <td class="p-2 border-b font-semibold text-emerald-600">${item.assignee}</td>
                        <td class="p-2 border-b text-slate-500">${item.deadline}</td>
                    </tr>`
                ).join('');
                
            } catch (error) {
                console.error(error);
                alert('Error processing notes. Please check your API key and try again.');
                document.getElementById('loading-state').classList.add('hidden');
            }
        });
    </script>
