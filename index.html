ADVANCED EDITION

Build a Pro-Level AI Meeting Assistant

Learn how to build a fully-featured, serverless web application complete with dark mode, markdown exports, and file uploads. Run it entirely in your browser using the Gemini API.

Welcome! In this workshop, you will build a sophisticated app that takes messy meeting notes and uses the Gemini API to instantly extract clean summaries, key discussion points, and structured action items.

What You Will Learn

  1. How to Get a Gemini API Key: Generating your free developer key using Google AI Studio.
  2. The Power of Client-Side Apps: How to build a fully functional web app using a single HTML file.
  3. Advanced Frontend Styling: Using Tailwind CSS for Dark Mode, interactive tabs, and glassmorphism effects.
  4. Robust API Integration: Connecting directly to `gemini-1.5-flash` with a "Smart Extractor" to guarantee perfect JSON data every time.

Step 1: Get Your Free Gemini API Key

To let your browser talk to Google's AI models, you'll need a free API key from Google AI Studio.

Do I have to pay for this?
No! Google offers a generous Free Tier which is perfect for this workshop. You do not need to enter a credit card to get your key.

  1. Go to Google AI Studio and sign in.
  2. Click Get API key in the dashboard.
  3. Click Create API key in new project.
  4. Copy your API key and save it. You will paste this into your web app!

Step 2: Set Up Your Workspace

You don’t need any complex software installations to get started.

  1. Create a folder on your computer named meeting-assistant.
  2. Inside it, create a file named index.html and open it in your favorite code editor.

Step 3: Building the Application Code

We are going to build this entire application inside your index.html file by copying and pasting three powerful chunks of code.
