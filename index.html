Build a Pro-Level AI Meeting Assistant

Learn how to build a fully-featured, serverless web application complete with dark mode, markdown exports, and file uploads. Run it entirely in your browser using the Gemini API.

Welcome! In this workshop, you will build a sophisticated app that takes messy meeting notes and uses the Gemini API to instantly extract clean summaries, key discussion points, and structured action items.

Step 1: Get Your Free Gemini API Key

To let your browser talk to Google's AI models, you'll need an API key. Think of this as a secure "passport" that tells Google you are authorized to use their services.

Do I have to pay for this?

Absolutely not! Google offers a generous Free Tier which is perfect for this workshop. It gives you access to the exact same models as the paid tier, just with lower rate limits (fewer requests per minute). You do not need to enter a credit card to generate your key!

  1. Go to Google AI Studio and sign in with your Google account.
  2. Click Get API key in the left-hand dashboard.
  3. Click the blue Create API key button.
  4. Copy your new API key and save it somewhere handy. You will paste this directly into your web app!

Step 2: Set Up Your Workspace

You don’t need any complex software installations, servers, or hosting to get started. Web browsers are incredibly powerful and can run this app locally!

  1. Create a folder on your computer named meeting-assistant.
  2. Inside it, create a new file named index.html.
  3. Open index.html in your favorite code editor (like VS Code, Notepad++, or Sublime Text).

Step 3: Building the Application Code

We are going to build this entire application inside your index.html file by copying and pasting three distinct chunks of code. Let's break down exactly what each piece does.

3.2 Application Logic & Settings (JavaScript Part 1)

Now we need to make the buttons work! We will open a <script> tag where our JavaScript will live.

Because this app runs entirely in the browser, we need a way to securely save the user's API Key without a database. We use a browser feature called localStorage. This saves the key securely on the user's local computer, meaning the key is never exposed to anyone else. We also add logic here for Dark Mode toggling and uploading text files!

Paste this immediately below the HTML you just pasted:

index.html (Part 2: UI & Settings JS)
    <script>
        // 1. Theme Management (Dark/Light Mode)
        const themeToggleBtn = document.getElementById('theme-toggle');
        const htmlElement = document.documentElement;
        if (localStorage.theme === 'dark' || (!('theme' in localStorage) && window.matchMedia('(prefers-color-scheme: dark)').matches)) {
            htmlElement.classList.add('dark');
        }
        themeToggleBtn.addEventListener('click', () => {
            htmlElement.classList.toggle('dark');
            localStorage.theme = htmlElement.classList.contains('dark') ? 'dark' : 'light';
        });

        // 2. API Key Modal & LocalStorage
        const settingsModal = document.getElementById('settings-modal');
        const apiKeyInput = document.getElementById('api-key-input');
        let userApiKey = localStorage.getItem('gemini_api_key') || '';
        
        if (userApiKey) document.getElementById('api-key-status-text').textContent = 'Key Saved';

        document.getElementById('open-settings').addEventListener('click', () => {
            apiKeyInput.value = userApiKey;
            settingsModal.classList.remove('hidden');
        });
        document.getElementById('close-settings').addEventListener('click', () => settingsModal.classList.add('hidden'));
        
        document.getElementById('save-api-key').addEventListener('click', () => {
            userApiKey = apiKeyInput.value.trim();
            localStorage.setItem('gemini_api_key', userApiKey);
            document.getElementById('api-key-status-text').textContent = 'Key Saved';
            settingsModal.classList.add('hidden');
            showToast('API key saved locally!');
        });

        function showToast(msg) {
            const toast = document.getElementById('toast');
            document.getElementById('toast-msg').textContent = msg;
            toast.classList.remove('translate-y-20', 'opacity-0');
            setTimeout(() => toast.classList.add('translate-y-20', 'opacity-0'), 3000);
        }

        // 3. File Upload Handler
        document.getElementById('file-upload').addEventListener('change', (e) => {
            const file = e.target.files[0];
            if (!file) return;
            const reader = new FileReader();
            reader.onload = (event) => {
                document.getElementById('notes-input').value = event.target.result;
                showToast('File loaded!');
            };
            reader.readAsText(file);
        });

3.3 The AI Brain & Smart Extractor (JavaScript Part 2)

This final piece is the true magic of our application. When the user clicks "Transform Notes", we bundle their text up alongside a strict JSON Schema. This schema forces the Gemini API to format its response perfectly as code (an array of action items with tasks, assignees, and deadlines) rather than a conversational paragraph.

The Smart Extractor: Because AI models sometimes hallucinate extra conversational text (like "Here is your data!") even when told not to, this code includes a powerful Regular Expression (Regex) that strips out any extra words, ensuring our app never crashes when trying to read the data! Note that we are using gemini-1.5-flash as our AI model.

Paste this final chunk immediately below the last one to complete your app!

index.html (Part 3: Gemini API Logic)
        // 4. Processing & Gemini API Call
        document.getElementById('process-btn').addEventListener('click', async () => {
            const rawNotes = document.getElementById('notes-input').value.trim();
            if (!rawNotes) return showToast('Please enter notes first.');
            if (!userApiKey) return showToast('Please set your API key first.');

            // Show loading state
            document.getElementById('empty-state').classList.add('hidden');
            document.getElementById('structured-output').classList.add('hidden');
            document.getElementById('loading-state').classList.remove('hidden');

            const apiUrl = `https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=${userApiKey}`;
            
            // Define exactly how we want the AI to format the data
            const payload = {
                contents: [{ parts: [{ text: `Organize these notes into JSON:\n\n${rawNotes}` }] }],
                systemInstruction: { parts: [{ text: "You are an executive assistant. Output ONLY valid JSON containing a summary and actionItems (task, assignee, deadline)." }] },
                generationConfig: {
                    responseMimeType: "application/json",
                    responseSchema: {
                        type: "OBJECT",
                        properties: {
                            summary: { type: "STRING" },
                            actionItems: {
                                type: "ARRAY",
                                items: {
                                    type: "OBJECT",
                                    properties: { task: { type: "STRING" }, assignee: { type: "STRING" }, deadline: { type: "STRING" } },
                                    required: ["task", "assignee", "deadline"]
                                }
                            }
                        },
                        required: ["summary", "actionItems"]
                    }
                }
            };

            try {
                let response = await fetch(apiUrl, {
                    method: 'POST',
                    headers: { 'Content-Type': 'application/json' },
                    body: JSON.stringify(payload)
                });

                if (!response.ok) {
                    const errData = await response.json().catch(() => ({}));
                    throw new Error(errData.error?.message || `API Error: ${response.status}`);
                }

                let result = await response.json();
                let candidate = result.candidates?.[0];

                if (candidate && candidate.content?.parts?.[0]?.text) {
                    let jsonText = candidate.content.parts[0].text;
                    
                    // SMART EXTRACTOR: Isolate JSON to prevent hallucination crashes
                    let jsonMatch = jsonText.match(/\{[\s\S]*\}/);
                    if (jsonMatch) {
                        jsonText = jsonMatch[0];
                    } else {
                        jsonText = jsonText.replace(/```json/gi, '').replace(/```/gi, '').trim();
                    }
                    
                    const parsedData = JSON.parse(jsonText);
                    renderResults(parsedData);
                } else {
                    throw new Error('Unexpected response format from AI.');
                }
            } catch (err) {
                console.error(err);
                showToast(err.message || 'Error processing notes. Check API Key.');
                document.getElementById('loading-state').classList.add('hidden');
                document.getElementById('empty-state').classList.remove('hidden');
            }
        });

        // 5. Display the Results
        function renderResults(data) {
            document.getElementById('loading-state').classList.add('hidden');
            document.getElementById('structured-output').classList.remove('hidden');

            document.getElementById('out-summary').textContent = data.summary || "No summary provided.";

            const tbody = document.getElementById('out-actions-tbody');
            tbody.innerHTML = '';
            (data.actionItems || []).forEach(item => {
                const tr = document.createElement('tr');
                tr.innerHTML = `
                    <td class="p-3 border-b border-slate-100 dark:border-slate-800 font-medium">${item.task || 'N/A'}</td>
                    <td class="p-3 border-b border-slate-100 dark:border-slate-800"><span class="px-2 py-1 bg-emerald-100 text-emerald-700 dark:bg-emerald-900/50 dark:text-emerald-400 rounded-full text-xs">${item.assignee || 'Unassigned'}</span></td>
                    <td class="p-3 border-b border-slate-100 dark:border-slate-800 text-xs text-slate-500">${item.deadline || 'No Date'}</td>
                `;
                tbody.appendChild(tr);
            });
        }
    </script>
</body>
</html>
